# 🛒 Store Stock & Sales Dashboard

Dashboard web para gestión de stock y análisis de ventas de una tienda de abarrotes.

## 🔧 Tecnologías
- HTML, CSS, JavaScript
- SQL Server
- Power BI

## 📊 Funcionalidades
- Visualización de productos y stock
- Análisis de ventas
- Filtros dinámicos
- Gráficos interactivos

## 📁 Estructura
- Frontend: interfaz web
- database.sql: estructura de base de datos
- data.json: datos simulados para frontend
